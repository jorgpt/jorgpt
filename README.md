# Jorge Hurtado

Founder of [PROCESA](https://procesamx.com). Chemical engineer.

PROCESA builds Super Intelligence (AI) systems for industrial and logistics companies. We connect agents to the tools a company already runs (SAP, SAT e-invoices, GPS and plant floor data entry) so leadership sees sales, collections, costs and alerts every day, with no double data entry for the team.

Clients with systems in production: Concretos Tancol, VELMEX and Naviera de Altamira.

## Stack

Claude and the Anthropic API · Model Context Protocol (MCP) · Claude Code · TypeScript / Node.js · Python · PostgreSQL · Railway · Vercel · Cloudflare
